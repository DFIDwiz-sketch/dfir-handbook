# 학습 경로 { #learning-path }

"Splunk를 쓸 줄 안다" 수준에서 **패킷을 읽고 공격을 이해하고, Windows와 Linux가 내부에서 무엇을 하는지 설명하고, 공격자 행위를 랩에서 재현하고, 엔드포인트와 네트워크 증거를 찾고, 악성코드를 분석하고, 탐지 규칙을 작성할 수 있는** 사람으로 성장하는 방법입니다. 이 조합이 바로 시니어 위협 헌터, DFIR 분석가, 악성코드 분석가, 레드팀원이 공통으로 갖춘 역량입니다.

| 페이지 | 용도 |
|---|---|
| [로드맵](roadmap.md) | 무엇을 어떤 순서로 배울지, 그리고 그 이유 — 기초부터 탐지 엔지니어링까지 여덟 가지 기둥 |
| [퍼플팀 주간 루프](purple-team-loop.md) | 학습 방법: **일주일에 ATT&CK 기법 하나**, 공격 → 아티팩트 → 쿼리 → 노트. T1059(PowerShell) 전체 실습 예시 포함 |
| [24개월 커리큘럼](curriculum-24-months.md) | 목표와 체크포인트가 있는 월별 계획 |
| [학습 자료](resources.md) | 기둥별로 정리한 무료·유료 랩, 강의, 책 |

!!! tip "한 문장으로 요약하면"
    넓이보다 깊이가 중요합니다: **네트워크 → Windows 내부 구조와 Active Directory → 공격 기법 → 악성코드와 리버스 엔지니어링 → 탐지 엔지니어링** 순서로 배우고, 모든 공격은 그 탐지와 함께 공부합니다.
