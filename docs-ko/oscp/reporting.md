!!! abstract "한 문장 요약"
    리포트가 증명해야 점수가 인정됩니다. VPN이 닫히면 실수는 되돌릴 수 없어요.

!!! info "뼈대 페이지"
    지금은 구조만 있습니다 — 아래 제목이 계획이에요. 공부하면서 각 부분을 채워 나가세요.

## 리포트 요구 사항 { #requirements }

- 공식 템플릿, PDF 한 개, 24시간 안에 업로드

## 증거 스크린샷 { #proof-screenshots }

- 플래그 내용 + IP 주소(+ `whoami`)가 **같은** 터미널 화면에 — 따로 찍은 두 장은 인정 안 됨

## 시험 중 노트 구조 { #exam-notes }

- 머신당 한 페이지: 스캔 → 정보 수집 → 초기 침투 → 로컬 정보 수집 → 권한 상승 → 플래그

## 템플릿과 도구 { #template }

- OffSec 템플릿, SysReptor, Obsidian

## 모의 리포트 { #mock-reports }

- 모의 시험마다 전체 리포트 쓰기

## 제출 체크리스트 { #submission-checklist }

- [ ] 모든 플래그에 증거 스크린샷이 있다
- [ ] 리포트만 보고 단계를 재현할 수 있다
- [ ] 요구 사항 페이지대로 PDF 이름과 업로드
