# 1부 — 네트워크 증거의 기초 { #part-1 }

!!! abstract "1부에서 다루는 것"
    디스크를 볼 수 없을 때 네트워크에 무엇이 남는지부터 시작합니다. 그다음 웹 프록시의 로그와 캐시, pcap 파일과 tcpdump·BPF, Wireshark와 tshark를 차례로 익히고, 증거를 어디서 어떤 장비로 수집하는지, 무엇이 조사를 어렵게 만드는지까지 다룹니다.
