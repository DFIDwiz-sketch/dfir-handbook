# Antisyphon Training { #antisyphon-training }

[Antisyphon Training](https://www.antisyphontraining.com/)은 John Strand와 Black Hills Information Security(BHIS)가 운영하는 보안 교육 브랜드입니다. 상당수 과정이 **Pay-What-You-Can**(원하는 만큼 내는) 방식으로, 요금이 접근 장벽이 되지 않도록 운영됩니다. 교육 철학은 한 문장으로 요약됩니다.

!!! quote ""
    공격자가 네트워크에 들어오는 것을 **실제로 막는 데** 직접 도움이 되지 않는 내용은 가르치지 않는다.
