# 분석가의 지각과 기억 { #analyst-cognition }

!!! abstract "한 줄 요약"
    경보를 골랐으니 이제 그게 진짜인지 판단해야 합니다. 좋은 분석가가 가장 자주 틀리는 곳이 바로 여기입니다. 이 섹션은 분석의 심리학으로 그 이유를 설명합니다. 능동적인 필터로서의 지각, 빨리 생기고 잘 안 바뀌는 마음가짐, 기대한 것만 보는 눈, 흔한 SOC 작업 방식과 SOC의 압박이 어떻게 섣부른 종결로 몰아가는지, 그리고 단기 기억의 한계, 경험과 장기 기억이 돕기도 하고 해치기도 하는 방식, 그걸 보완하는 습관(쪼개기, 밖으로 꺼내 적기)까지.

## 꼭 기억할 것 { #must-know }

1. 잘못된 종결은 대부분 분류가 아니라 검증에서 시작된다.
2. 불확실성은 자연스럽게도(빠진 데이터) 생기고 심어지기도(속임수) 한다. 둘 다 예상한다.
3. 편향은 무의식적이다. 안다고 사라지지 않는다. 절차가 없앤다.
4. 지각은 마음가짐을 거친 해석이다. 마음가짐은 몇 초 만에 생긴다.
5. 새 증거는 첫 이론에 끼워 맞춰진다. 데이터가 모호하고, 확신하고, 몸을 실었을 때 가장 심하다.
6. 기대한 것을 본다. 기대하지 않은 것은 알아차리는 데 더 많은 증거가 필요하다.
7. "맞나?"가 아니라 "틀렸다면 무엇이 보일까?"를 묻는다.
8. 가설과 대안을 적고, 닫기 전에 사건 전체를 다시 읽고, 새 눈을 쓴다.
