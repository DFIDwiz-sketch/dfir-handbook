# 보안 사고 모델 { #mental-models }

!!! abstract "한 줄 요약"
    앞 섹션은 지각과 기억의 실수를 막는 방법이 정확한 정신 모형을 많이 갖추는 것이라고 했습니다. 이 섹션이 그 연장통입니다. 공격, 방어, 위협 인텔리전스의 표준 모델 — 캡슐화와 OODA 루프, 사이버 킬 체인과 캠페인 분석, 심층 방어, NIST 사이버보안 프레임워크와 사고 대응 주기, 위협 인텔리전스 수준, 인텔리전스 주기와 F3EAD, 다이아몬드 모델, 공격 트리와 그래프 사고, 위협 모델링, 고통의 피라미드, MITRE ATT&CK — 을 각각 어디에 쓰는지, 실제 경보와 로그에서 어떻게 보이는지, 언제 무엇을 꺼낼지와 함께 다룹니다.

## 꼭 기억할 것 { #must-know }

1. 모델을 여러 개 모은다. 모델마다 상황의 어떤 면은 밝히고 어떤 면은 가린다.
2. 악성은 2계층부터 7계층 어디에나 있다. 요즘 공격 상당수는 7계층에서만 보인다.
3. 실제로 검사한 계층만 깨끗하다고 말한다. 못 본 계층은 못 봤다고 적는다.
4. 파일에도 겹이 있다. 컨테이너가 아닌 것이 나올 때까지 계속 푼다.
5. OODA: 관찰, 방향 잡기, 결정, 행동 — 상대가 있는 불확실성 속에서 행동하는 루프.
6. 방향 잡기는 모형과 맥락이 데이터를 만나는 곳이다. 모형이 틀리면 속도는 쓸모없다.
7. 속도가 이긴다. 사전 승인 플레이북은 결정을, 좋은 맥락은 방향 잡기를 줄인다.
8. 빠른 것과 서두르는 것은 다르다. 범위를 알기 전에 행동하면 공격자를 가르치게 된다.
