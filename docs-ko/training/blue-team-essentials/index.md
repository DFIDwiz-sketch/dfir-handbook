# Blue Team Essentials { #blue-team-essentials }

<div class="dfir-meta" markdown>
**기준 교재:** SANS SEC450 *Blue Team Fundamentals: Security Operations and Analysis* (2022) · **방식:** 교재를 한국어 강의 노트로 다시 풀고, 2026년 기준 보충·정정을 덧붙임
</div>

!!! abstract "이 섹션의 성격"
    SOC 분석가가 매일 보는 데이터(DNS, HTTP, 이메일, 엔드포인트 로그 등)를 **"왜 필요한가 → 무엇인가 → 실제로 어떻게 생겼나 → SOC에서 언제 쓰나"** 순서로 정리합니다. 교재의 원리는 그대로 따르되, 2022년 이후 바뀐 도구·기법·위협 환경은 **[변경됨]**, 교재대로 하면 지금은 위험하거나 틀린 부분은 **[주의]**/**[정정]**, 교재에 없지만 실무에 꼭 필요한 내용은 **[보충]**으로 표시합니다.
