# Blue Team Essentials { #blue-team-essentials }

!!! abstract "이 섹션의 성격"
    SOC 분석가가 매일 보는 데이터(DNS, HTTP, 이메일, 엔드포인트 로그 등)를 **"왜 필요한가 → 무엇인가 → 실제로 어떻게 생겼나 → SOC에서 언제 쓰나"** 순서로 정리합니다. 최근 바뀐 도구·기법·위협 환경은 **[변경됨]**, 흔히 틀리게 알려졌거나 옛 방식대로 하면 위험한 부분은 **[주의]**/**[정정]**, 실무에 꼭 필요한 내용은 **[보충]**으로 표시합니다.

## 주제 { #topics }

<div class="grid cards" markdown>

-   :material-dns:{ .lg .middle } **DNS**

    ---

    DNS 구조와 레코드, 기록 수집과 안전한 조사, 도메인 신호, 비인가 DNS·터널링·블록체인 DNS·IDN, 암호화 DNS, 그리고 수상한 DNS 기록 판별표.

    [:octicons-arrow-right-24: DNS](dns/index.md)

-   :material-web:{ .lg .middle } **HTTP**

    ---

    웹 서버와 웹셸, URL 해부와 피싱 속임수, GET·POST와 로그, 그 밖의 메서드(CONNECT·HEAD·OPTIONS·PUT·DELETE·TRACE), 요청 헤더 읽기, 확인 문제와 해설.

    [:octicons-arrow-right-24: HTTP](http/index.md)

</div>
