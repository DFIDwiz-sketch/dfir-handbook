# Silver C2 { #silver-c2 }

C2를 처음 배우는 학생을 위한 학습 노트입니다. 운영자의 작업 흐름과 방어자가 관찰할 수 있는 증거를 함께 살펴봅니다.

!!! note "도구 이름"
    메뉴는 요청한 이름인 **Silver C2**로 유지합니다. 도구의 정확한 이름은 Bishop Fox가 개발한 **Sliver**입니다. 명령어·기술 설명·참고 자료에서는 정확한 이름을 사용합니다.
