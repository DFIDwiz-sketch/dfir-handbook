# 문답 — 학습 범위와 다음 단계 { #course-coverage-and-next-steps }

## 원강좌의 내용을 모두 다뤘나요? { #have-we-covered-the-whole-course }

**아직이며 남은 주제가 있습니다.** 네트워크 조회 설명 후 학습자가 질문한 내용입니다. 원강좌와 지금까지의 수업을 대조했고, 이 페이지는 15강까지의 진도를 반영합니다.

강의 번호는 한 번에 이해하기 쉽게 나눈 학습 단위입니다. 원강좌의 구간과 일대일로 대응하거나 완료 비율을 뜻하지 않습니다. 추가 질문에 따라 개별 주제를 자세히 확장했습니다.

## 현재 다룬 범위 { #current-coverage }

| 원강좌의 주제 | 현재 수업 상태 |
|---|---|
| C2 구성, Listener, Implant 생성·전달 | 명령과 증거의 차이를 포함해 설명 |
| Session·Beacon, 체크인과 작업 시간 | 대상 선택·대화형 Session 예시와 함께 설명 |
| Payload·Stager·Loader | 개념 설명; 강좌 전용 Loader 구현은 재현하지 않음 |
| 백신 탐지와 실행 파일 분석 | 탐지·조치·결과 설명; PE-bear·DefenderCheck 직접 분석은 남음 |
| 계정과 권한 | 8·15강에서 토큰·Deny only·특권 상태·무결성 수준 설명; 도메인·공유 조사는 남음 |
| Armory와 BOF | 13강과 BOF·COFF·OBJ 문답에서 패키지 준비·코드 구조 설명 |
| 프로그램·.NET Assembly·BOF 실행 | 14강에서 방식과 명령 형태 설명; 설명용 Assembly를 직접 빌드·실행한 실습은 아님 |
| 프로세스·네트워크·환경 파악 도구 | 기본 인터페이스·연결 설명; 추가 진단 도구 실습은 남음 |
| Windows 서비스 설정 오류와 권한 상승 | 구체적인 사례 분석이 남음 |
| 다른 신원을 이용한 실행과 횡적 이동 | 추가 설명이 남음 |
| 포트포워딩·SOCKS5 | 명령 예시와 SSH 가상환경으로 설명 |
| ProxyChains·NetExec을 통한 내부 SMB 접근 | 추가 설명이 남음 |
| 원강좌의 인증 공격 예시 | 아직 자세히 가르치지 않음 |
| SMB 공유 권한과 범위를 정한 파일 수집 | 추가 설명이 남음 |

‘설명’은 게시한 수업의 상태이며 모든 학습자가 실행에 성공했다는 뜻은 아닙니다. 명령 예시, 실제 실행, 성공 증거는 별개입니다.

## 추가한 보충 내용은 무엇인가요? { #added-supplements }

이해를 돕기 위해 다음 설명을 추가했습니다.

- 웹 서버에서 내부 SSH VM으로 연결하는 고정 포워딩·SOCKS5 실습 구성.
- SSH 인증 기록, 출발지 해석, 임시 포트, TCP와 인증의 구분.
- LISTEN·ESTABLISHED의 한계, 라우팅·방화벽·가상 네트워크 분리·컨테이너 포트 매핑.
- BOF와 COFF의 보고서·DOCX 비유, 목적 파일의 컴파일·링크, 대상에 맞춘 로더 준비.
- 학습자의 답과 판단 근거를 포함한 상세 해설, 메모리 실행과 실행 프로세스의 차이.

운영 흐름을 증거·문제 진단에 연결하는 보충이며 원강좌의 모든 주제가 끝났다는 뜻은 아닙니다.

- [15강의 권한 카드·Deny only·파일 접근 예시](lesson-15-windows-tokens-and-privileges.md)도 복습할 수 있습니다.

## 이어갈 학습 순서 { #suggested-continuation }

15강의 토큰 해석을 바탕으로 추가 진단 도구의 발견 사항을 해석하는 흐름으로 이어갑니다. 도구가 설정 오류를 보고한 것과 실제로 사용할 수 있는 권한이나 작업 성공의 증거를 구분합니다. 이후 서비스 설정, 인증·인가, 내부 SMB 흐름에 연결할 수 있습니다.

권한 원리는 [8강](lesson-8-identity-tokens-and-permissions.md), 패키지 준비는 [13강](lesson-13-armory-and-bof-basics.md), 실행 방식은 [14강](lesson-14-exe-dotnet-and-bof-execution.md)에서 복습합니다.
