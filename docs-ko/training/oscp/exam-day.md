!!! note "이 페이지 구성"
    하루 계획과 노트에 복사해 쓸 원점수·증빙 기록표입니다. 시험은 심리적 요소가 큽니다 — 에너지와 긴장 관리가 기술만큼 중요해요.

!!! warning "시험 시작 시각 확인 — 2026년 12월 1일 채점 변경"
    **2026년 12월 1일 08:00 GMT 이전 시작** 시험은 **원점수 70점 이상**, **그 시각부터 시작**하는 시험은 **100~500점 척도에서 척도 점수 400점 이상**이 합격 기준입니다. 척도 점수제에서 원점수 70점·80점은 합격을 보장하지 않으며, 400/500은 원점수 80%라는 뜻이 아닙니다. 예약한 시작 시각을 확인하세요. 여기서는 독자의 시험 날짜를 가정하지 않습니다. [채점 방식 설명](exam-format.md#scaled-scoring)과 공식 [Scoring FAQ](https://help.offsec.com/hc/en-us/articles/54589877508884-OSCP-Equated-Scaled-Scoring-FAQ)를 참고하세요.

## 시험 전 { #before }

- **일찍 예약.** 슬롯이 적어요 — 한 달 전인 경우가 많습니다. 시작 시간을 고르고, 직전 이동은 피하세요.
- **시작 시간을 신중히.** 가장 맑은 시간이 처음 ~6시간(standalone 하나 + AD 세트)에 겹치게. 많은 사람이 오전 중반을 고르고, 낮잠 뒤 밤 시작을 선호하는 사람도 있어요. 너무 일러 멍하지도, 너무 늦어 어려운 대목에 번아웃이 오지도 않게.
- **환경은 전날 준비:** Kali VM 스냅샷, 도구 / 워드리스트 / 스크립트 제자리에, 리포트 템플릿 열어 두기, 두 번째 인터넷(휴대폰 핫스팟), 예비 전원.

## 시작과 감독 { #proctoring }

- 셋업(신분 확인, 화면 공유, 웹캠, VPN)은 한 시간까지 걸릴 수 있고 23시간 45분을 깎지 않습니다 — 다만 VPN이 느릴 수 있으니 당황 마세요.
- 감독관이 시험 중 화면 재공유나 웹캠 재확인을 요청할 수 있어요. 정상이니 침착하게 하고 계속하세요.
- AI 금지, 외부 도움 금지, 웹캠 내내 켜기 → [시험 규칙](exam-format.md#exam-rules).

## 공격 순서 { #order }

1. **standalone 하나로 워밍업** (~2~3시간 제한). 흐름 타기 — 꼼꼼한 정보 수집, 익스플로잇, 기록. 버티면 확보한 발판을 증빙하고 넘어가세요.
2. **AD 세트, 맑을 때.** 사슬로 묶인 40점; 초반의 놓친 크리덴셜이나 피벗이 나머지를 막으니 맑은 머리로 → [Active Directory](active-directory.md).
3. AD를 확보한 뒤 **남은 standalone으로**, 미뤄 둔 것에 새 눈으로.
4. **목표 완수와 증빙을 계속하세요.** 척도 점수제에는 공개된 원점수 합격 목표가 없습니다. 남은 시간은 유망한 단서, 증빙 점검, 휴식에 배분하세요. 예상 점수가 중단 이유가 되어서는 안 됩니다. 변경 이전 시작 시험의 [70점 조합](exam-format.md#passing-combinations)도 OffSec이 증빙을 인정해야 성립하며, 추가 원점수는 올바른 기록을 대신하지 못합니다.

## 시간 제한과 휴식 { #breaks }

- 막힌 단서마다 정해진 예산을 주고, 끝나면 대상을 바꿉니다.
- 진짜 휴식을 — 가볍게 먹고(과식은 둔해짐), 자리를 뜨고, 수분 보충. 돌파구는 휴식 뒤에 온다는 말이 유명하죠.
- 한 시간에 한 번쯤 일어나세요. 23시간 45분에 수면이 포함됩니다 — 짧은 낮잠이 한 시간 더 노려보는 것보다 나을 수 있어요.

## 원점수·증빙 기록표 { #point-tracker }

시험 노트에 복사해 실시간으로 유지하세요. 컨트롤 패널의 목표와 원점수 배점을 따릅니다. 직접 계산한 합계는 채점 전의 예상치이며, 척도 점수제의 결과를 예측할 수 없습니다.

중간 지점쯤 [점수 전략](exam-format.md#scoring-strategy)에 따라 미완료 목표, 빠진 증빙, 유망한 단서와 체력을 점검하세요. 이 기록표를 척도 점수로 환산하거나 합격·불합격 판정표로 쓰지 마세요.

## 막혔을 때 { #stuck }

- 정보 수집으로 돌아가세요 — 필요한 건 보통 이미 화면에 있는데 안 읽은 거예요.
- 다른 머신으로 바꾸세요; 미뤄 둔 문제가 시간이 지나면 저절로 풀리는 경우가 많습니다.
- 내 노트를 다시 읽어, 적어 두고 안 쓴 크리덴셜이나 정보를 찾으세요.
- 소용돌이에 빠지지 마세요. 합격자는 "돌아와서 20분 만에 풀었다"고 쓰고, 불합격자는 "머리가 하얘졌다"고 씁니다. 머신은 안 변해요 — 사람이 변하는 거예요.

## 실습 시간이 끝난 뒤 { #after }

- VPN이 닫히기 **전에** 모든 플래그를 컨트롤 패널에 제출하세요.
- 쉬고 나서 24시간 창에 리포트를 쓰세요 → [리포트](reporting.md). 노트가 좋으면 거의 조립입니다.
- **예상 원점수가 낮아 보여도 리포트를 제출하세요.** 척도 점수제에서는 원점수만으로 합격 여부를 알 수 없으며, 리포트를 제출하지 않으면 합격할 수 없습니다.
- 머신으로 돌아갈 수 없으니 빠진 스크린샷은 되돌릴 수 없어요 — 리포트를 [제출 체크리스트](reporting.md#submission-checklist)와 대조하세요.
- Scoring FAQ에 따라 리포트 제출 후 이메일 결과 안내까지 **최대 15영업일**을 예상하세요 (종전 10영업일; Exam Guide의 Results 항목에는 아직 10영업일로 기재).
