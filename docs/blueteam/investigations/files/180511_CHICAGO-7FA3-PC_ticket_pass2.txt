#SUMMARY#
------------------------------------------------------------------------------------------
Host 10.0.14.129 (Chicago-7fa3-PC, user faith.hoffman) is infected.
The host was already infected before the capture started. The first infection is not in
this capture.

At 02:08:04Z the malware sent host details to its C2 server (lysedsohap.com).
The C2 reply told it to download 3 files. The host downloaded 3 encrypted files from a
hacked WordPress site (wansaiful.com) 1 second later.

After the downloads:
- A new component sent 2 small encrypted POSTs to the same C2 (likely stolen passwords).
- The host tried 1,522 domain logons through the DC in 32 seconds (password guessing).
- A second C2 channel started over TLS (robwassotdint.ru, self-signed certificate).
- The TLS C2 sent about 1.5 MB to the host at 02:40-02:42Z (more modules or settings).

Both C2 channels were still active when the capture ended (02:49Z).
No large uploads to external hosts were seen. The 2 small POSTs (440 B) cannot be read,
so treat the saved passwords on the host as stolen.
Malware family is NOT confirmed (no hash lookup or vendor signatures used).
