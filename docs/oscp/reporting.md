!!! abstract "In one sentence"
    Points only count if the report proves them — and mistakes are permanent once the VPN closes.

!!! info "Skeleton page"
    Structure only for now — the headings below are the plan. Fill each section as you study.

## Report requirements { #requirements }

- Official template, single PDF, upload within 24 h

## Proof screenshots { #proof-screenshots }

- Flag contents + IP address (+ `whoami`) in the **same** terminal — two separate screenshots do not count

## Note structure during the exam { #exam-notes }

- One page per machine: scan → enumeration → initial access → local enumeration → privesc → flags

## Template & tools { #template }

- OffSec template, SysReptor, Obsidian

## Mock reports { #mock-reports }

- Write a full report after each mock exam

## Submission checklist { #submission-checklist }

- [ ] Every flag has a proof screenshot
- [ ] Steps reproduce from the report alone
- [ ] PDF naming and upload per the requirements page
