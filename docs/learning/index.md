# Learning Path

How to grow from "I can use Splunk" to someone who can **read a packet and understand the attack, explain what Windows and Linux are doing internally, reproduce attacker behaviour in a lab, find the endpoint and network evidence, analyse the malware, and write the detection**. That combination is what senior threat hunters, DFIR analysts, malware analysts and red teamers have in common.

| [24-month curriculum](curriculum-24-months.md) | Month-by-month plan with goals and checkpoints |

!!! tip "The one-sentence version"
    Depth beats breadth: learn **networks → Windows internals & Active Directory → offensive techniques → malware & reverse engineering → detection engineering**, and study every attack together with its detection.
