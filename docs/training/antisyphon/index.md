# Antisyphon Training

[Antisyphon Training](https://www.antisyphontraining.com/) is the security-training brand run by John Strand and Black Hills Information Security (BHIS). Many courses are **Pay-What-You-Can**, so cost is not a barrier to entry. The teaching philosophy, in one line:

!!! quote ""
    Don't teach anything that doesn't directly help **actually stop** an attacker from getting into your network.

<div class="grid cards" markdown>
