    Adversary Techniques¶

    Attack techniques mapped to MITRE ATT&CK, each written the same way: how the attack works → attacker commands → artifacts left behind (host + network) → detection (Splunk/Zeek) → response. Every page links back to the Windows, Network and Splunk sections where the underlying artifacts and queries live.

    By ATT&CK tactic¶

    Tactic Technique Page
    Initial Access / Execution Phishing → user execution (macro, LNK, ISO, cradle) Phishing delivery
    Execution / Defense Evasion PowerShell download cradles & encoded commands PowerShell cradles
    Credential Access LSASS memory dumping LSASS dumping
    Credential Access Kerberoasting Kerberoasting
    Lateral Movement / Defense Evasion Pass-the-Hash Pass-the-Hash
    Lateral Movement / Execution PsExec & SMB admin shares PsExec & SMB
    Lateral Movement / Execution WMI & WinRM remote execution WMI & WinRM
    Persistence Services, scheduled tasks, Run keys Persistence

    A typical intrusion, in this section's pages¶

    flowchart LR
    P[Phishing delivery] --> PS[PowerShell cradle]
    PS --> BEA[Beacon / C2]
    BEA --> L[LSASS dumping]
    L --> K[Kerberoasting]
    L --> PTH[Pass-the-Hash]
    PTH --> LM[PsExec / WMI / WinRM]
    K --> LM
    LM --> PER[Persistence]
    PER -.-> BEA
    LM --> DOM[Domain / objective]

    Read left to right: a lure runs a cradle, the cradle plants a beacon, the operator dumps LSASS for credentials, uses those to Kerberoast or pass-the-hash, moves laterally with PsExec/WMI/WinRM, and drops persistence on each new host. Each box is a page; each transition is a place to detect and contain.

    Pages¶

    • Phishing delivery — macro/LNK/ISO → shell, download cradles, Mark-of-the-Web
    • PowerShell cradles — -enc decoding, 4104 scoring, in-memory loading
    • LSASS dumping — Sysmon 10 access masks, comsvcs/procdump, credential theft
    • Kerberoasting — 4769 RC4, SPN enumeration, offline cracking
    • Pass-the-Hash — NTLM type-3/type-9, hash reuse
    • PsExec & SMB — ADMIN$ write + 7045 service chain
    • WMI & WinRM — wmiprvse/wsmprovhost parents, WMI persistence
    • Persistence — services, tasks, Run keys, and the wider ASEP list

    How to use these pages in an investigation¶

    Start from what you observed (a suspicious process, an alert, a beacon) and read the matching page's artifacts table to know what else to collect, then run its detection queries to scope how far it spread. The response section says what to contain and rotate. For the underlying mechanics — what a given event ID means, how an artifact is parsed, the exact SPL commands — follow the links into Windows, Network and Splunk.

    Adding a technique

    python new.py adversary/<name> -t technique — the template already has the five-part structure. It appears in the sidebar automatically.
